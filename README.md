# 🌐 Portfólio — Jhennyfer Despesi

Landing page pessoal desenvolvida em HTML, CSS e JavaScript puro, com design moderno, tema escuro e animações de scroll.

---

## 📁 Estrutura do projeto

```text
portfolio/
├── index.html    # estrutura e conteúdo
├── style.css     # estilização completa
├── script.js     # animação de scroll reveal
└── README.md     # documentação
```

---

## ✨ Funcionalidades

- **Navegação fixa** com efeito de blur ao rolar
- **Cursor piscante** no nome (referência a terminal/código)
- **Seções:** Hero, Sobre, Formação, Projetos e Contato
- **Card em destaque** para o projeto Bluery com badge da FETEPS
- **Timeline** de formação acadêmica
- **Scroll reveal** — elementos animam ao entrar na tela
- **Design responsivo** para mobile e desktop

## 🚀 Como usar

1. Baixe os três arquivos (`index.html`, `style.css`, `script.js`) na mesma pasta
2. Abra o `index.html` no navegador — sem necessidade de servidor ou instalação
3. Para publicar online, veja as opções abaixo

---

## 🌍 Como publicar gratuitamente

### GitHub Pages
1. Crie um repositório no GitHub com o nome `seu-usuario.github.io`
2. Faça upload dos arquivos
3. Acesse `https://seu-usuario.github.io`

### Vercel
1. Acesse [vercel.com](https://vercel.com) e crie uma conta
2. Importe o repositório do GitHub
3. Deploy automático em segundos

### Netlify
1. Acesse [netlify.com](https://netlify.com)
2. Arraste a pasta do projeto direto no painel
3. Seu site estará no ar imediatamente

## 🛠️ Personalização

| O que mudar | Onde |
|---|---|
| Link do GitHub | `index.html` — atributo `href` nos botões e links de contato |
| Foto ou imagem do Bluery | Substituir o bloco `.bluery-showcase` no card em destaque |
| Novos projetos | Adicionar um novo `.project-card` dentro de `.projects-grid` |
| Cores | Variáveis `:root` no início do `style.css` |
| Textos | Diretamente no `index.html` |
