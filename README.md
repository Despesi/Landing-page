## 👩‍💻 Apresentação

Este projeto é minha landing page de portfólio pessoal, desenvolvida do zero com **HTML, CSS e JavaScript puro** — sem frameworks, sem dependências externas.

O objetivo foi criar uma página que me represente de verdade: com identidade visual própria, tema escuro, tipografia moderna e uma experiência agradável de navegar. Cada detalhe foi pensado, desde o cursor piscante no nome — uma referência ao universo do código — até as animações suaves que aparecem conforme você rola a página.

Nela você encontra um pouco sobre quem eu sou, minha trajetória acadêmica na ETEC e no IFSP, os projetos que já desenvolvi — incluindo o **Bluery**, meu TCC que chegou à **FETEPS** — e formas de entrar em contato comigo.

Foi um projeto que me desafiou a unir técnica e criatividade, e que representa bem onde estou hoje na minha jornada como desenvolvedora.

## 🖥️ Sobre o projeto

Landing page de portfólio pessoal desenvolvida do zero com **HTML, CSS e JavaScript puro** — sem frameworks, sem dependências. Design com tema escuro, tipografia moderna e animações suaves de scroll.

<br/>

## ✨ Funcionalidades

- 🔝 Navegação fixa com efeito de **blur** ao rolar
- ⌨️ Cursor piscante no nome — referência a terminal
- 📌 Seções: **Hero · Sobre · Formação · Projetos · Contato**
- 🏆 Card em destaque para o **Projeto Bluery** com badge da FETEPS
- 📅 Timeline de formação acadêmica
- 🎞️ **Scroll reveal** — elementos animam ao entrar na tela
- 📱 **Totalmente responsivo** para mobile e desktop

<br/>
